# SQL Scripts for Cuppa Messenger Database

## Структура папок:

- `/administration` - Скрипты для администрирования и мониторинга
- `/backup` - Инструкции и скрипты для резервного копирования

## Как использовать:

### Миграции:
1. Выполнять по порядку после создания основных таблиц
2. Рекомендуется выполнять на тестовой среде перед продакшеном

### Администрирование:
- `database_health_check.sql` - для регулярного мониторинга
- `maintenance_operations.sql` - для обслуживания (выполнять с осторожностью)
- `user_management.sql` - для управления пользователями

### Резервное копирование:
- Использовать инструкции из `backup_instructions.sql`
- Для автоматизации использовать `automated_backup_script.sh`

## Важные замечания:

1. Делайте бэкап перед выполнением миграций
2. Проверяйте результаты деструктивных операций


## Контакты:
Для вопросов по базам данных обращаться к администратору БД.
